# NowListening

A minimal horizontal Now Playing theme for OBS Studio, designed for the [zapdel's Now Playing Plugin](https://github.com/zapdel/zapdel-now-playing).

## Features

- Minimal horizontal music display
- Album artwork support
- Track title and artist display
- Animated audio equalizer
- Playback progress bar
- Slide-in and slide-out animations
- Blue accent color and dark background

## Installation

1. Install the zapdel's Now Playing plugin for OBS Studio.
2. Copy the `NowListening` folder into the plugin's `data/themes/` directory.
3. Open the properties of the Now Playing source in OBS Studio.
4. Select **NowListening** from the theme list.

## Theme dimensions

- Default width: 1920 px
- Default height: 64 px
